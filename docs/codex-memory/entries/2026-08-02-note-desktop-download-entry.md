# 笔记桌面版下载入口

## 需求

网页版包含文章、图库、导航和笔记等多个模块，桌面应用只服务笔记功能，因此不能在全站导航中使用含义宽泛的“客户端”入口。

## 实现

- 在网页笔记左侧栏标签列表下方增加下载卡片，并放在 `ElScrollbar` 外部绝对定位于侧栏底部，目录滚动时卡片保持不动。
- 使用“下载笔记桌面版”作为无障碍标签和悬停提示，明确入口所属功能。
- 新窗口跳转至 `https://github.com/lovethewind/ltw_notes_desktop/releases`，并设置 `noopener noreferrer`。
- 回收站视图继续显示下载入口，保证整个笔记模块内均可发现。

## 验证

- 组件定向测试覆盖文案、目标地址、新窗口及安全属性。
- 通过 TypeScript 类型检查和生产构建。

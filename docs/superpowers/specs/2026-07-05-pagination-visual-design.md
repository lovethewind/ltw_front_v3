# 分页组件视觉统一设计

## 目标

统一首页文章流、文章列表和图库中的 Element Plus 分页样式，使其延续 Header 的轻液态视觉语言，同时保持分页信息清晰、交互稳定，并兼容深色模式。

## 设计方案

- 在现有 Element Plus 全局样式入口中增加分页主题，不修改各页面的分页结构、数据请求或事件处理。
- 页码、上一页和下一页使用紧凑的圆角按钮；默认态采用轻透明背景和细边框，悬停态使用浅蓝高光。
- 当前页使用主题蓝渐变、白色文字和克制的蓝色阴影，形成明确但不过度突出的视觉焦点。
- 禁用态降低对比度并移除浮动反馈；键盘聚焦态保留清晰的焦点环。
- 总数、跳转文字、页容量选择器和输入框沿用同一套文字、边框、圆角与交互颜色。
- 深色模式使用深色半透明底、青蓝高光和更轻的边框，不改变页面既有主题切换方式。
- 小屏幕保持当前响应式布局与分页功能，不额外增加毛玻璃外层容器。

## 影响范围

- 仅修改分页相关的全局 SCSS 样式。
- 覆盖首页、文章列表及图库现有的 `el-pagination` 实例。
- 不修改 Vue 组件逻辑、接口、路由、分页参数或 Element Plus 配置。

## 验收标准

- 所有现有分页实例呈现一致的轻液态胶囊样式。
- 当前页、悬停、按下、聚焦、禁用状态均清晰可辨。
- 浅色和深色模式下文字与控件具有足够对比度。
- 分页切换、页容量选择及跳页行为与改造前一致。
- 项目类型检查、构建及相关测试不因样式改造产生回归。

## 非目标

- 不抽取新的 Vue 分页组件。
- 不更改分页布局、每页数量或业务逻辑。
- 不对其他 Element Plus 控件进行顺带重构。
